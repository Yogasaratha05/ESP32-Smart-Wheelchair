# ESP32 Smart Wheelchair

## Project Description

This project develops an ESP32-based smart wheelchair prototype with Bluetooth voice control, GPS tracking, obstacle detection, and a web-based monitoring dashboard.

## Features

* Bluetooth-based movement commands
* Forward, backward, left, right, and stop controls
* GPS location tracking using a GPS module
* IR sensor-based obstacle detection
* Buzzer alert
* Web dashboard for movement and location monitoring
* Adjustable motor speed

## Hardware Components

* ESP32 development board
* Motor driver and DC motors
* IR obstacle detection sensor
* GPS module
* Buzzer
* Battery and connecting wires

## Software Requirements

* Arduino IDE
* ESP32 board package
* TinyGPSPlus library

## Project Status

Prototype — hardware testing and safety validation required.

## Disclaimer

This project is intended for educational purposes. It must not be used to transport a person until all movement controls, emergency stops, and obstacle-detection functions have been thoroughly tested.
